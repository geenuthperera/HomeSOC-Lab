# Documentation

This directory contains the setup, configuration, and implementation documentation for the HomeSOC lab.

## Planned Documentation

| Document | Purpose |
|---|---|
| Wazuh Agent Setup | Installation and enrollment of the Windows endpoint |
| Sysmon Setup | Installation and configuration of Microsoft Sysmon |
| Windows Logging Configuration | Security and PowerShell logging configuration |
| Wazuh Log Collection | Integration of Windows and Sysmon telemetry with Wazuh |
| Lab Configuration | HomeSOC environment configuration and testing notes |

## Documentation Approach

Each guide will include:

1. Purpose of the configuration
2. Required software or settings
3. Step-by-step implementation
4. Verification steps
5. Troubleshooting notes
6. Screenshots where appropriate

## Current Status

Documentation will be added progressively as the HomeSOC environment is deployed and tested.
